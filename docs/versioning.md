# Versioning

Matrix follows Semantic Versioning: `MAJOR.MINOR.PATCH`.

- A major version may break the public API.
- A minor version adds compatible features.
- A patch version fixes behavior without changing the expected API.
- `0.x` versions remain experimental: a minor release may still require migration.
- Every public change must be added to `CHANGELOG.md` and have a migration note when necessary.
