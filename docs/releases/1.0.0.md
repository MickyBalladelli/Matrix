# Matrix 1.0.0 — 2026-08-30

Matrix 1.0.0 is the first stable release of the fine-grained reactive JavaScript framework.

- Signals, Computeds, Effects, scopes, components, lifecycle hooks, templates, keyed lists, forms, resources, routing, scoped CSS, plugins, and DevTools are available through the documented public API.
- The package remains ESM-only and keeps the documented entry points and optional JSX runtime. Applications should use the stable `@mickyballadelli/matrix` package instead of the alpha npm tag.
- Runtime stability includes safer component rollback, error boundaries, reactive DOM updates, input handling, browser navigation, and cleanup behavior.
- DevTools snapshots redact sensitive values by default and expose component, reactive graph, router, and performance timeline inspection.
- The repository includes local unit, type, browser, compatibility, security, integration, example-application, performance, package, and release checks.
- The root production bundle is 55,113 bytes minified, 18,992 bytes gzip, and 16,950 bytes Brotli.
